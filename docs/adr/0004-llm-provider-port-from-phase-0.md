# LLM gọi qua port LlmProvider từ Phase 0

Phase 0 gọi LLM qua một port `LlmProvider` với đúng một production implementation dùng OpenAI SDK cho endpoint OpenAI-compatible do operator cấu hình, cùng `FakeProvider` cho test/offline dev. Operator khai báo tường minh transport (`responses` hoặc `chat-completions`) và structured-output mode (`json-schema-strict` hoặc `json-object`); adapter không tự fallback sang request thứ hai vì lời gọi đầu có thể đã phát sinh chi phí. Decoder/validation của hệ thống vẫn là contract quyết định cuối cùng trước khi cache/persist. Credential chỉ được inject vào worker deployment, không vào HTTP API process.

Lý do thật là **testability và giam kiểu SDK**, KHÔNG phải đoán trước việc swap provider. Có port nghĩa là cắm được `FakeProvider` để test pipeline nhanh/rẻ/ổn định (không gọi API thật, không tốn tiền, không phụ thuộc mạng), và domain (logic sinh/validate quiz) không import kiểu của SDK OpenAI. Hai transport chỉ là chi tiết adapter nhằm tương thích endpoint operator đang có mà không khóa port vào Responses API. Platform Model do operator cấu hình; Custom AI Configuration được resolve theo Owner qua cùng port khi secret-management và trust boundary sẵn sàng. Quyền Custom AI không phụ thuộc gói; xem ADR-0021. Credit preflight và reserve trước enqueue theo ADR-0022, còn billing/model routing nâng cao được hoàn thiện ở Phase 4.
